Sign in

This page edits the website's Brand and Aircraft lists directly in the GitHub repository . Saving makes a commit, and the live site updates within a minute or two.

  1. On GitHub, open Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Under Repository access, pick Only select repositories and choose this repository.
  3. Under Permissions → Repository permissions, set Contents to Read and write. Then generate the token and paste it below.

Add a brand

Brands are listed A–Z on the website, in the home Part Search's Brand list, the header menu and the Brands page. A new brand gets its own page right away; products added to it later show up there. To show a logo, put public/brands/<slug>.svg (or .png / .webp) in the repository.

Add an aircraft model

Models are grouped by manufacturer on the website (home Part Search, Shop by Aircraft, product filters). Choose an existing manufacturer or type a new one. Separate several models with commas.
